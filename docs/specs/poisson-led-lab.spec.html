01 · Problem statement

The optical hypothesis needs its own clean bench and control.

The existing prototype begins with an acoustic waveform and derives light from it. That makes the LED result inseparable from decisions made for sound. This experiment instead reveals what a bounded, positive, steady Poisson current field does before acoustic interpretation and compares it with a conventional deterministic PWM condition.

Current lacks authority

An audio-first path allows an acoustic decision to change the LED waveform. The optical experiment cannot then distinguish Poisson behavior from source-model behavior.

Rate is easily misread

Speed must continue to mean one total lamp rate. At the maximum, 48,000 Arrivals/s total becomes an expected 6,000 Arrivals/s per Channel—not 48 kHz on every Channel.

A monitor can hide convergence

Automatic level matching would keep high-density modulation loud even as the current becomes steadier. The monitor must preserve the current’s changing AC magnitude.

No control condition

Without a rate- and mean-matched PWM baseline, the experiment cannot distinguish a Poisson-specific result from ordinary high-frequency visual integration.

02 · Solution

Run stochastic current beside a periodic control, then choose what to monitor.

Poisson emits exact Arrivals and uniformly marks one of eight Channels. PWM drives all eight Channels in phase at Λ/8 cycles/s. Both conditions advance continuously from the same Total Event Budget and Target Mean Current; PWM Pulse Current trades pulse height against automatically derived duty without changing that mean. Separate LED banks remain visible while Monitor Source selects only the diagnostics, scopes, and direct AC Current Monitor.

03 · User stories

The lab should make the hypothesis falsifiable.

Every control and measurement exists to reveal current behavior, not to decorate it.

  1. As an experimenter, I want to sweep one logarithmic total rate from 1 through 48 kHz, so that sparse flashes and dense convergence occupy one continuous control.
  2. As an experimenter, I want a PWM Control with the same total event budget, so that the Poisson hypothesis has a conventional deterministic baseline.
  3. As an experimenter, I want both conditions to run simultaneously in separate LED banks, so that changing the monitored source cannot substitute a later trial for a parallel control.
  4. As an experimenter, I want PWM Channels phase-aligned, so that hidden phase staggering cannot artificially flatten Aggregate White.
  5. As an experimenter, I want every Arrival assigned uniformly to exactly one of eight Channels, so that Channel count does not multiply the lamp’s selected event rate.
  6. As an experimenter, I want a ninth white monitor formed from all eight currents, so that I can inspect the complete field without inventing a ninth stream.
  7. As an experimenter, I want average current held approximately constant as Speed changes, so that increasing brightness or saturation cannot masquerade as convergence.
  8. As a smart-light experimenter, I want Target Mean Current to travel continuously through 100%, so that full brightness is an ordinary slider endpoint rather than an unavailable state.
  9. As an experimenter, I want to change current fall time, so that I can study how response bandwidth changes overlap and fluctuation.
  10. As an experimenter, I want to hear only the AC portion of fused current, so that audible modulation corresponds directly to optical modulation.
  11. As an experimenter, I want fixed monitor gain, so that genuinely diminishing modulation is allowed to become quiet.
  12. As an experimenter, I want manual logarithmic Monitor Gain up to the exact target-dependent no-clipping bound, so that quiet modulation can be auditioned without changing the optical experiment or allowing browser clipping.
  13. As an experimenter, I want each virtual LED to show the arithmetic mean of every current sample in its display interval, so that no Arrival is silently discarded.
  14. As an experimenter, I want a shared 1 s, 100 ms, 10 ms, or 1 ms scope timebase, so that I can move between convergence and individual PWM pulse morphology.
  15. As an experimenter, I want to vary PWM Pulse Current while holding the commanded mean fixed, so that I can compare tall narrow pulses, shorter wider pulses, and continuous reduced current fairly.
  16. As an experimenter, I want connected minimum and maximum envelopes, so that a sustained positive or negative plateau remains visible instead of collapsing into zero-length vertical marks.
  17. As an experimenter, I want a separate fixed-scale audio oscilloscope, so that I can inspect the exact DC-to-AC conversion without normalization disguising its magnitude.
  18. As an experimenter, I want mean, RMS modulation, peak, limiter proximity, and observed rate together, so that I can distinguish convergence from clipping or missed events.
  19. As an experimenter, I want Stop to force zero sound and zero current immediately, so that stopped state is unambiguous.
  20. As a future hardware designer, I want the browser’s display-refresh limitation stated plainly, so that this page is not mistaken for a physical flicker-perception test.
04 · Implementation decisions

One comparison Module owns the complete signal contract.

The Poisson LED Lab Engine Interface advances two fixed-source condition engines from shared settings and exposes one monitor choice. The worklet adapts both rendered blocks to audio and diagnostic messages; the page adapts those messages to two LED banks, pixels, and controls.

Exact timing

Inter-arrival gaps are exponentially distributed. Multiple Arrivals may occur inside one 48 kHz sample interval and each contributes independently; sample coincidence never merges event identity or energy.

Matched PWM control

Every PWM Channel uses one shared phase and frequency Λ/8. PWM Pulse Current selects the on-state current from the commanded Target Mean Current through 100%; duty is derived as Target Mean Current ÷ PWM Pulse Current, so their product always preserves the shared mean. On-time is duty ÷ frequency and silence is (1 − duty) ÷ frequency; both remain read-only evidence because independently controlling them would redefine frequency and duty. At the lower pulse-current endpoint duty reaches 100% and the output becomes continuous reduced current. The eight cycle counts still sum to Λ. The bank header displays commanded mean, pulse current, and duty separately from each LED's short Frame-Mean Current. PWM advances beside Poisson and ignores Current Fall Time because that control belongs only to Poisson Current Responses.

Monitor, not switch

Monitor Source selects which completed condition block feeds the scopes, metrics, and audio output. It does not start, stop, reset, or reconfigure either condition.

Uniform routing

Every Arrival receives one uniform Channel mark. Poisson splitting gives eight independent streams with expected rate Λ/8 and preserves Λ as the total lamp rate.

Positive response

An Arrival injects a positive exponential current response with selectable fall time τ. There are no spectral, spatial, acoustic, or event-morphology marks.

Mean-held charge

Event charge varies inversely with expected Channel rate and response duration. At high overlap, the smooth limiter’s expected output approaches Target Mean Current. Sparse bounded pulses cannot always reach that target and must report their actual mean honestly.

Full-DC limit

Below 100%, Poisson uses finite mean-held event charge and PWM uses the selected duty cycle. Exactly 100% is the explicit limit of both models: every Channel outputs continuous unit current while Poisson Arrivals and PWM phase continue advancing. Direct subtraction of the 100% target makes the Current Monitor exactly and immediately silent.

Smooth limit

Raw positive shot current maps through u/(1+u). The current remains continuous in value, nonnegative, and below 100%, without a hard clipping plateau.

White fusion

Aggregate White equals the arithmetic mean of the eight instantaneous Channel currents. It has no Arrivals, response state, or independent gain of its own.

Direct sound monitor

Every fused-current sample is translated vertically by subtracting the commanded Target Mean Current. This preserves the waveform point for point without a DC filter, history, decay, or frequency shaping. The only later operation is explicit logarithmic manual Monitor Gain, defaulting to the 2× safe maximum at a 50% target. Its target-dependent bound is Gsafe = 1 ÷ max(Ī, 1 − Ī), so no possible bounded current sample can exceed browser full scale. Changing Target Mean Current updates the slider maximum and clamps its value immediately. The signal is copied equally to both speakers with no automatic normalization, limiting, or compression. Because sparse bounded Poisson current may not attain its target exactly, it may retain a small inaudible residual offset rather than altering the waveform to force a measured zero mean.

Dual oscilloscopes

The Current Oscilloscope uses a fixed 0–100% scale. The Audio Oscilloscope plots the exact target-centered, pre-gain samples on a fixed −1 to +1 current-unit scale with a zero line. A shared timebase selects 1 s, 100 ms, 10 ms, or 1 ms. Both draw connected per-pixel minimum and maximum envelopes, retain unresolved excursions, preserve same-sign plateaus, and perform no visual normalization.

Frame integration

Every worklet sample contributes to the arithmetic mean displayed by each DOM LED. Measurements and oscilloscopes are diagnostic views, not selectable rendering modes.

Isolation

This standalone file and its Modules do not call, configure, or revise the existing generated-audio path. The two experiments share only durable domain definitions for Arrival, Channel, Speed, and Aggregate White.

05 · Testing decisions

Prove behavior at the public Interface.

Tests exercise the owned Poisson LED Lab Engine rather than reproducing its internals in a fake. Browser validation verifies the AudioWorklet adapter and rendered controls.

Arrival evidence

A long seeded run must reproduce exactly, approach the requested total rate, distribute counts near Λ/8, and preserve the sum of Channel counts as total Arrivals.

Signal evidence

Every Channel sample remains in [0,1), Aggregate White equals the exact sample mean, and every pre-gain audio sample equals Aggregate White minus Target Mean Current with no hidden transformation or state.

Gain evidence

The Monitor Gain slider must map equal travel to equal gain ratios from 0.01× through the exact target-dependent no-clipping bound. A 50% target permits 2×; 25% or 75% permits 1.33×; 100% permits 1×. Changing Target Mean Current must update and enforce the bound immediately. Gain may alter only the browser GainNode; LED currents, event timing, worklet diagnostics, and the pre-gain Audio Oscilloscope must remain identical.

Continuity evidence

One render and arbitrarily partitioned renders must return identical Channel current, fused current, and audio samples for the same seed and settings.

Rate evidence

The maximum clamps to 48,000 total Arrivals/s and reports 6,000 expected Arrivals/s per Channel. Dense current must show lower RMS modulation than a tenfold slower field at the same target and fall time.

PWM evidence

At an 8,000/s total event budget, 25% target, and 100% Pulse Current, every Channel must produce the same binary 1 kHz waveform, exactly 1,000 rising edges/s, 25% mean current, and 8,000 combined edges/s. At 50% Pulse Current, its only current values must be 0% and 50%, derived duty must be 50%, and mean current must remain 25%. Pulse Current may never fall below Target Mean Current. Both conditions must satisfy the same direct commanded-mean subtraction rule.

PWM timing evidence

At 1 kHz per Channel, a 25% target with 100% Pulse Current must report 0.25 ms on and 0.75 ms silent. Reducing Pulse Current to 50% must report 0.50 ms on and 0.50 ms silent while preserving the same 25% commanded mean.

Full-DC evidence

At a 100% target, both conditions must emit exact unit current on all eight Channels and Aggregate White while their underlying event counts continue. Direct subtraction of the commanded unit mean must make every audio-monitor sample exactly zero without NaN, infinity, clipping logic, filter state, or a stopped clock.

Display evidence

The page exposes eighteen accessible meters in two labeled condition banks, one accessible monitor selector, one shared scope timebase, exact total/per-Channel language, the fixed frame-mean rule, both fixed-scale oscilloscopes, current diagnostics, and one explicit sound-monitor switch.

Scope evidence

A known PWM pulse train must retain zero and one plateaus after display reduction. When multiple excursions fall inside one column, the same Interface must retain their true minimum and maximum without normalization or invented zero crossings.

Browser evidence

Start must animate both banks, Monitor Source and shared-control changes must not restart either condition, sound disable must leave all LEDs running, Stop must darken all eighteen meters, and the console and worklet must remain error-free at 48 kHz.

06 · Out of scope

This is a stochastic-current instrument, not yet a driver.

The page measures a mathematical and perceptual direction before circuit topology is selected.

Excluded source behavior

  • Recorded or generated environmental sound
  • Per-event amplitude or response-family marks
  • Distance, propagation, stereo position, material, or wavelength-driven timbre
  • Shared Channel coupling or a ninth event stream

Excluded optical claims

  • Calibrated luminance, radiometry, or chromaticity
  • Retinal persistence or human flicker thresholds
  • Proof of 48 kHz optical perception on a 60 Hz display
  • Thermal behavior or LED efficiency

Deferred hardware

  • DAC resolution and reconstruction filtering
  • Constant-current topology and feedback bandwidth
  • MCU event scheduling and interrupt load
  • PCB, power, thermal, and safety requirements
07 · Further notes

The virtual LEDs integrate; both scopes remember and zoom.

A typical display cannot emit the worklet’s 48 kHz optical waveform. Its LED circles therefore report one honest exposure-like frame mean. The fixed-scale Current and Audio Oscilloscopes carry the DC and AC evidence lost to refresh-rate integration, while their shared timebase separates long-run convergence from pulse morphology. PWM is a scientific comparison condition, not the planned hardware decision. A future physical build must repeat both conditions with a measured current driver and photodiode before any claim about imperceptible modulation is accepted.
